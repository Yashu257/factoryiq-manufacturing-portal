# 🚀 FactoryIQ Manufacturing Excellence Portal

A modern Manufacturing Visibility Portal built using **React + Tailwind CSS**.  
This project was developed as part of a technical interview task to demonstrate frontend architecture, UI design, and modular dashboard development.

🔗 **Live Demo:** https://factoryiq-manufacturing-portal.vercel.app  
📂 **GitHub Repo:** https://github.com/Yashu257/factoryiq-manufacturing-portal

---

## 🧠 Project Overview

FactoryIQ is a centralized manufacturing dashboard that provides visibility into production, quality, supply chain, and analytics in a clean and scalable UI.

The goal of this project was to build a multi-module manufacturing portal **without backend integration**, focusing purely on frontend architecture and user experience.

---

## ✨ Features

- 📊 Interactive Dashboard
- 🏭 Production Visibility Module
- ✅ Quality Management Section
- 🔗 Supply Chain View
- 📈 Analytics & Reporting UI
- 🔐 Authentication UI (Login/Signup)
- 🎨 Modern responsive design
- ⚡ Fast Vite build setup
